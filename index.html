AI agent evaluation

ResolveAI

Stress-tests chat and voice support agents before they reach customers.

Source on GitHub
60+multi-turn scenarios
6industries covered

Problem

Support agents rarely fail on the happy path. They fail when they invent policy, call tools in the wrong order, leak PII, miss a safety escalation, or claim success after an API error. Those failures need to be repeatable tests, not anecdotes.

Approach

  • Scenario library with messy multi-turn transcripts, hidden evaluator-only ground truth, expected tool-call sequences, and escalation triggers for fraud, PII, safety, and repeated human requests.
  • Suites for prompt injection, API failure handling, RAG faithfulness, refund abuse, and human handoff.
  • Prompt v1 vs v2 comparison with regression warnings and side-by-side transcripts.
  • Voice Lab that scores interruption handling, speech uncertainty, escalation timing, and call-summary accuracy.

Key decision

Every run ends in a deployment call (ready for pilot, needs guardrails, or not production ready) instead of a raw score, because that's the decision a team actually has to make. Without an API key the engine falls back to a deterministic demo mode, so evaluations stay reproducible.

Event-driven backend

Crisis Pulse

Real-time disaster intelligence and geo-alerting on AWS serverless.

Source on GitHub

Problem

Incident signals arrive in bursts from many sources. The system has to classify and store every event, avoid duplicates, and alert only on what matters, without anyone babysitting servers.

Approach

  • Kinesis absorbs bursty ingest; a Python classifier Lambda assigns disaster type and a severity score.
  • Writes go to DynamoDB for low-latency geo queries and to S3 for archive and replay.
  • Only high and critical events go to EventBridge, then through an alert Lambda to SNS.

Key decisions

  • Deterministic event IDs make retries idempotent, so at-least-once delivery doesn't create duplicate alerts.
  • Dual write (DynamoDB + S3) separates hot reads from durable history.
  • EventBridge between classify and alert keeps alerting decoupled, so new channels don't touch the classifier.
  • Everything in Terraform, with alarms on DLQ depth and error rate from day one.
